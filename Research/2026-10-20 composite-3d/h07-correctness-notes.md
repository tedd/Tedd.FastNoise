## Exactness failure

Test: `CompiledStack3DTests.ExceptionalCoordinatesAndContributionsPreserveOriginalBits`, three theory cases: Add, Multiply, Lerp.

Both layers use identical OpenSimplex2 seed 91 requests: frequency .013f, FBm, three octaves, weighted strength .375f, gain .5f, lacunarity 2f, disabled LOD. Identical requests intentionally exercise DAG CSE. The first layer has Blend=Lerp with a NaN factor, which is ignored by the established first-layer rule.

The first contribution case has these bits:

| Parameter | Bits |
|---|---|
| First amplitude | 7FC12345 |
| First offset | FFC54321 |
| Second amplitude | FFC54321 |
| Second offset | 7FC12345 |
| Second Lerp factor | 3E800000 (.25f) |

All three theory cases first fail on SIMD, sample 0, **finite coordinates**: region origin (-13.5f, 7.25f, -3.125f), width 9, height 1, depth 1, step .75f. Original fused executor: **7FC12345**. Typed DAG: **FFC54321**. The preceding scalar comparison passes this case. These are distinct quiet NaN payloads/signs, not a finite-value or numerical-tolerance discrepancy.

The demonstrated failure is NaN-payload selection across typed contribution/blend execution. Register/operand selection is a plausible mechanism; no before/after failing-instruction capture establishes its precise origin. Do not attribute it conclusively to CSE. Bit equality was never relaxed.

## Retained fix

Typed Rows3 receives the resolved layers. After its SIMD delegate returns, any NaN lane triggers recomputation of the complete original SIMD group through `StackFill.Evaluate3<VectorOps,...>` using identical base XYZ. A scalar/tail NaN triggers the original scalar Evaluate3. The original executor therefore supplies payload bits. Classification is based on the result, covering NaNs generated by finite-setting overflow as well as explicit NaN contributions. There is no finite-parameters-imply-finite-output assumption.

A temporary complete-worker-range replay passed nine focused cases, then was replaced by the requested per-group/per-sample recomputation. The final complete CPU run validates the retained granularity. Common-path classification and rare-path recomputation cost require measurement.
